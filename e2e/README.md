# Браузерные проверки

Установка браузера: `npx playwright install chromium`.
Запуск: `npm run test:e2e`.

Playwright поднимает отдельный Next.js на порту 3100 с пустым
`NEXT_PUBLIC_API_URL`. Рабочий сервер и реальные аккаунты не используются.
Каждый тест получает отдельный браузерный контекст и локальные данные.
Сервис-воркер заблокирован; внешние тайлы карты не загружаются.

Скриншоты в `snapshots/` получены из исходной версии приложения до
рефакторинга, с фиксированными датой, локалью и размерами экрана.
Проверяются вход, список и форма поездки, обзор, deep links и панель маршрута.
Допустимое отличие изображения — 1% пикселей; артефакты различий и trace
появляются в `test-results/`.

Обновляйте эталоны командой `npm run test:e2e -- --update-snapshots`
только после просмотра и согласования изменений оформления.
